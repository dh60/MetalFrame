# MetalFrame

A video player for macOS 26+ on Apple Silicon.

[Download](https://github.com/dh60/MetalFrame/releases/latest) · [Changelog](CHANGELOG.md)

![MetalFrame](screenshot.png)

## Features

- MKV, WebM, MP4, and MOV playback
- HDR playback with optional tone mapping
- MetalFX upscaling and Lanczos downscaling
- SRT and ASS subtitles in MKV files
- Playlists and folder playback, including subfolders
- Shuffle, repeat, and automatic playback of the next file
- Open M3U/M3U8 playlists and save playlists as M3U8

Supported audio: AC-3, E-AC-3, AAC, FLAC, Opus, and DTS.
DTS-HD plays its DTS core; DTS-HD lossless and TrueHD aren't supported yet.

## Controls

Move the pointer to show playback controls. Press **P** to select, add, or remove
videos from the playlist. Choose shuffle and repeat modes in the controls or the
**Playback** menu. Save a playlist with **File → Save Playlist…**.

| Key | Action |
| --- | --- |
| Space | Play / pause |
| Left / Right | Back / forward 10 seconds |
| Up / Down | Volume up / down 10% |
| Q / W | Previous / next file |
| P | Show / hide playlist |
| F | Fullscreen |
| S | Cycle subtitle tracks |
| A | Cycle audio tracks |
| T | Toggle HDR tone mapping |
| I | Show video details and Off / Fit / Fill controls |
| ⌘O | Open files, a folder, or a playlist |
| ⇧⌘O | Open a folder |
| ⌥⌘O | Add files, folders, or playlists |
| Esc | Quit |
